STRONGER PERSONAL COMMITMENT MODE

Fewer easy escapes.
No impossible promises.

Exhausted apps get a saved lockout for the current day. A missing usage snapshot won’t clear it. Revoking Usage Access alone won’t clear it while Enough’s accessibility service is running.

Android still lets you disable that service, clear app data, or uninstall the app. A normal app cannot make the phone owner powerless. This is not an unbreakable device lock.

CLEAR ANSWERS

Before you commit.

Can I block Instagram using only this website?

No. Websites cannot enforce Android app limits. Browser mode is a voluntary session timer. Install the Android app for device-level observation and the Home-return guard.

Is there really no way to bypass the Android limit?

There is no in-app extra-time or today’s-limit override. But a personal phone’s owner can disable the service, clear data, or uninstall it. OS-level package suspension requires a separately managed device and is not included. Split-screen, browser versions, cloned apps, clock changes with reboot, and manufacturer background restrictions can affect protection.

Are my messages or photos read?

No. The Android app does not request internet access, screen-content retrieval, camera, or photo access. It uses app identities and usage timing locally. The website has no analytics or account system; its browser timer stores its state locally. Vercel processes ordinary web requests to serve the site and APK.

Why does it need Accessibility access?

It observes app-window changes and presents the budget guard. The app explains this before asking you to enable the service. You can disable it in Android Settings. It does not inspect screen text or messages.

Is this ready for everyone’s main phone?

Not yet. Automated budget tests and build checks are useful, but they do not replace phone testing. This release is marked alpha and has a device-test checklist in the open-source repository. Essential/system apps are excluded; Instagram is included even if preinstalled; other system apps remain excluded.
